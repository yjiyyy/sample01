# 로비 상점과 인벤토리

Play에서 로비의 상점을 열면 새 UI가 적용됩니다. 씬을 다시 배치할 필요가 없습니다.

## 관리 위치

- `Assets/Data/Lobby/Shop/Category_Weapons.asset`: 무기 목록, 표시 순서, 판매 여부, 가격과 결제 재화. 기존 플레이어 무기 11종을 등록했습니다. 최초 가격은 500골드부터 100씩 증가하는 테스트용 설정입니다.
- `Category_Other.asset`: 기타 카테고리. 현재는 비어 있으며, 소모품 지급 기능은 아직 지원하지 않습니다.
- `LobbyShopCatalog.asset`: 카테고리 연결, NPC 초상화·대사, 인벤토리 최대 칸 수(기본 10).
- `Assets/Resources/UI/LobbyShopSettings.asset`: 위 카탈로그를 불러오는 연결. 보통 수정하지 않습니다.

무기 추가: Category_Weapons의 Items에 한 줄을 추가하고 Weapon에 기존 WeaponDataSO를 넣습니다. 가격과 재화를 지정합니다. 이름은 비우면 원래 무기 이름을 사용하고, 아이콘·무게·장착 모델은 무기 SO에서 가져옵니다. Description은 기능 설명이 아닌 선택 시 NPC 대사입니다. 빈 대사는 기본 대사를 사용합니다. 무기 ID는 고유해야 하며 변경하지 않는 것이 좋습니다.

## 동작

무기를 누르면 근력과 관계없이 장착 모습을 미리 봅니다. 실제 장착 슬롯이나 인벤토리는 바뀌지 않습니다. 상점을 닫거나 다른 패널로 바꾸면 실제 장비로 돌아옵니다.

구매는 계정 전체에서 한 번만 가능합니다. 인벤토리 한 칸을 차지하며, 장착해도 칸은 비워지지 않습니다. 빈칸·재화가 부족하거나 이미 보유한 상품은 구매할 수 없습니다. 구매 후 현재 슬롯을 교체했을 때의 전체 무게를 검사하여 장착하거나 인벤토리에만 보관합니다. 기존 무기는 보유 목록에 남습니다.

로비의 인벤토리 메뉴에서 구매한 무기를 확인하고 장착합니다. 왼쪽 슬롯 변경으로 1/2번 슬롯을 선택할 수 있습니다. 같은 무기를 한 캐릭터의 두 슬롯에 동시에 넣을 수는 없습니다. 같은 보유 무기를 여러 캐릭터의 장착 설정에 지정하는 것은 가능합니다.

보유 목록과 돈·젬은 계정 공용이며 장착 조합은 캐릭터별입니다. 씬 이동과 전투 진입 후에도 유지되고, 게임 종료 후 재실행 또는 Play 재시작 시 초기화됩니다. 아직 디스크 저장은 하지 않습니다. 전투 중 임시 무기 변경·탄약은 로비 장착 설정을 덮어쓰지 않습니다.

## 편집 미리보기

03_Lobby 씬에서 `Tools > Setup Lobby Shop Panel`을 실행하면 UI를 편집 화면에서 확인할 수 있습니다. 씬은 자동 저장하지 않습니다. 미리보기에서 구매는 불가능하며 실제 장착 미리보기는 Play에서 확인합니다. 이동한 Upgrade 폴더에 맞게 업그레이드 설정 도구 경로도 수정했습니다.

`WeaponShopVerification.Run`은 Unity를 종료하는 배치 전용 검사입니다. 일반 편집 중 실행하지 마세요.
