# 로비 업그레이드 관리

## 화면 확인

- Play를 종료하고 `03_Lobby` 씬을 엽니다.
- `Tools > Setup Lobby Upgrade Panel`을 누르면 편집 화면에서 새 패널을 확인할 수 있습니다.
- 미리보기가 마음에 들면 씬을 저장하세요. 이 메뉴는 씬을 자동 저장하지 않습니다.
- 씬에 이전 패널이 남아 있어도 Play에서 업그레이드를 열면 새 패널로 갱신됩니다.

## 설정 위치

`Assets/Data/Lobby/Upgrade_001_Cool_SO.asset`부터 `Upgrade_005_Miki_SO.asset`까지 캐릭터별 에셋을 편집합니다.

- 대상 캐릭터: 기본 능력치를 가져올 CharacterDataSO입니다. 이 SO의 PlayerConfig를 기준으로 표시와 전투를 계산합니다.
- 업그레이드 목록: 표시할 HP / STA / SPD / STR, 순서, 이름, 아이콘입니다. 같은 능력은 한 번만 등록하세요.
- 1회 증가량: 구매할 때 증가하는 실제 수치입니다.
- 최대 강화 횟수: 추가 구매 가능한 횟수입니다. 기본 능력은 횟수와 가격에 포함되지 않습니다.
- 최종 최대값: 막대 오른쪽 끝입니다.
- 첫 구매 가격 / 회당 가격 증가: 다음 가격 = 첫 가격 + 구매 횟수 × 증가 가격입니다.
- 선택 시 NPC 대사: 해당 행을 선택했을 때 보여줄 대사입니다.

기본값 + 증가량 × 횟수와 최종 최대값이 다르면 Inspector에 경고가 표시됩니다. `최대값을 기본값 + 증가량 × 횟수로 맞추기` 버튼으로 맞출 수 있습니다. 실제 구매는 횟수와 수치 중 먼저 도달한 제한에서 멈춥니다. 마지막 증가분이 상한을 넘으면 상한까지만 적용하며 구매 전 수치에 반영합니다. 설정을 잘못 낮춰도 기존 기본 능력을 감소시키지는 않습니다.

NPC 초상화, 공통 대사, 등록된 캐릭터 목록은 `LobbyStatUpgradeCatalog.asset`에서 관리합니다. `Resources/UI/LobbyUpgradeSettings.asset`은 이 카탈로그를 불러오는 연결이므로 일반적으로 수정하지 않습니다.

새 캐릭터는 Create > Game > Lobby > Character Upgrades로 에셋을 만들고 대상 캐릭터를 지정한 뒤 카탈로그의 캐릭터 목록에 추가합니다. 기본값을 확인하고 최대값을 맞춘 후 미리보기를 갱신하세요.

## 표시와 구매

- 흰색은 기본 능력, 청록색은 이미 구매한 강화량입니다.
- 노란 테두리와 다음 수치는 현재 선택한 행에만 표시됩니다.
- 행을 누르면 선택만 바뀝니다. 우측 하단 버튼으로 실제 구매합니다.
- 버튼에는 선택한 능력과 다음 가격이 표시됩니다. 골드 부족, 최대치, 설정 누락 시 비활성화됩니다.
- NPC 영역에는 대사만 표시합니다.
- 캐릭터마다 막대의 최대값이 다르므로 실제 능력 비교는 숫자를 확인하세요.

## 저장

`AccountSession`이 게임 실행 중의 돈·젬, 선택 캐릭터와 캐릭터별 강화 횟수를 보관합니다. 씬을 이동하거나 캐릭터를 바꿔도 유지됩니다. 돈·젬은 모든 캐릭터가 공유하고, 강화 기록은 캐릭터 데이터 에셋의 고유 ID별로 구분합니다. SO에는 플레이 중의 구매 기록을 저장하지 않습니다.

게임을 완전히 종료하고 다시 실행하면 돈·젬과 강화 횟수는 0으로 시작합니다. Unity에서도 Play를 종료하고 다시 시작하면 초기화됩니다(도메인 리로드 비활성화 포함). 과거 PlayerPrefs 강화 기록은 삭제하지 않고 읽기와 쓰기만 중단합니다. 향후 세이브 시스템은 AccountSession에 계정 데이터를 복원하도록 연결하면 됩니다. PlayerResources는 이 공통 지갑을 화면과 픽업에 연결하는 역할입니다.

## 로비 카메라

로비에 진입하면 패널을 닫고 선택 캐릭터를 중앙에 보여줍니다. 상점·업그레이드를 열면 패널 구도로 이동하고 돌아가기를 누르면 기본 구도로 돌아옵니다. Main Camera의 LobbyUpgradeCameraBlend에서 기본/패널 구도와 Blend Seconds를 조정할 수 있습니다. 컴포넌트 메뉴의 Preview Lobby Camera / Preview Panel Camera로 Play 전에도 확인할 수 있습니다. 편집에서 패널 구도를 저장해도 실행 시 기본 구도로 시작합니다.

## 검증

`LobbyUpgradeVerification.Run`은 배치 검증용입니다. 새 에셋의 초기 준비, 계산 검사, 임시 캐릭터 구매·표시 검사와 화면 캡처를 수행한 후 Unity를 종료하므로 평소 편집 중에는 실행하지 마세요. 씬은 저장하지 않습니다.
