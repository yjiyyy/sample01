# 옵션의 개발자 치트

Play에서 `옵션 → 개발자 치트`를 누릅니다. 기존 전투 초상화에서도 같은 메뉴가 열립니다.

- 로비: 돈 +100 / +1,000, 젬 +100 / +1,000, 돈·젬 전부 0.
- 전투: 재화 버튼과 기존 상점·티켓·HP·회피 게이지·무기·업그레이드 기능.
- 플레이어 지갑이 없는 타이틀 등에서는 재화 버튼이 비활성화됩니다.
- 내용이 길면 목록을 마우스 휠, 터치/마우스 드래그, 오른쪽 스크롤바로 이동합니다.
- 제목과 보유량, 돌아가기 버튼은 목록과 함께 스크롤되지 않습니다.
- 옵션에서 열었다면 돌아가기 버튼은 옵션으로 복귀합니다. 전투 옵션의 일시정지는 옵션을 닫을 때까지 유지됩니다.

추가한 돈·젬은 PlayerResources를 통해 계정 공통 지갑에 반영되므로 상단 HUD와 로비 강화 버튼에 즉시 표시됩니다. 씬 이동과 캐릭터 변경 후에도 유지되며, 게임 종료 후 재실행하거나 Unity의 Play를 다시 시작하면 초기화됩니다. 현재 디스크에 저장하지 않습니다.

버튼과 메뉴는 Unity 에디터 또는 Development Build에서만 제공됩니다. 치트 컴포넌트의 Enable In Build를 끄면 개발 빌드에서도 메뉴를 열 수 없습니다.

씬이나 프리팹을 다시 배치할 필요 없이 실행 중 기존 옵션에 버튼이 연결됩니다. 편집 모드에서 기존 옵션의 버튼 배치를 미리 보려면 OptionsUI 컴포넌트의 메뉴에서 `Refresh Developer Cheat Button`을 실행하고 씬을 직접 저장할 수 있습니다.

`DevCheatVerification.Run`은 배치 검증 전용입니다. 로비를 실행하여 버튼·재화·스크롤·일시정지·자식 메뉴를 검사하고 화면을 캡처한 후 Unity를 종료합니다. 평소 편집 중에는 실행하지 마세요. 씬은 저장하지 않습니다.
